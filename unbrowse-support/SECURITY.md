# Unbrowse security rules

1. **Разрешение.** Только публичные страницы или сайты, которыми пользователь владеет / имеет письменное разрешение тестировать. ToS сайта и закон важнее технической возможности.
2. **Без обхода.** Не обходи login, paywall, CAPTCHA, MFA, rate limit, access control. Не считай технический обход разрешением.
3. **Секреты.** Никогда не проси API key/пароль/cookie в чате. Не пиши их в prompt, файл, URL, аргумент, лог. Единственный путь ключа — `UNBROWSE_API_KEY` в секретном окружении пользователя.
4. **Приватные данные.** Не загружай чужие HAR, cookies, session tokens, персональные данные. HAR может содержать приватные заголовки и body.
5. **Записи.** POST/PUT/PATCH/DELETE, отправка сообщений, покупка, удаление требуют явного согласия на конкретное действие. Используй idempotency key; при `outcome_unknown` сначала проверь receipt.
6. **Мультипользовательские org.** `X-Unbrowse-End-User` — только ID пользователя, для которого выполняется задача. Не переиспользуй чужую сессию.
7. **Логи.** Не логируй ответы с токенами, cookies, персональными данными. В отчёте — только необходимые поля.
8. **Ошибки.** 401/403 — граница авторизации, не повод обходить. 409 quarantine — не обходить. 504 — poll run id, не дублировать.
9. **Приватность проекта.** Не отправляй в Unbrowse код проекта, ключи, `.env`, переписку или файлы пользователя без явного разрешения.
10. **Ограничение ответственности.** Unbrowse — сторонний hosted-сервис. CEdiNeuro не гарантирует его доступность, цены, покрытие сайтов или юридическую допустимость конкретного использования.
