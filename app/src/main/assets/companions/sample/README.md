# Sample companion atlas

This is a 4 x 8 sprite sheet for testing the companion importer.

- frame: 32 x 32 px
- sheet: 128 x 256 px, transparent
- columns: 4 frames
- rows: idle, sleep, think, work, team, happy, worry, offline
- frame time: 160 ms
- image-rendering: nearest

The art is an original pixel test asset released under CC0. Replace it with your own
sheet in the same layout, or use Settings -> Companion -> Choose sprite sheet.
