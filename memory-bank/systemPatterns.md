# System patterns

- Native libraries are aligned for 16 KB pages after symbol stripping and again in the APK (`zipalign -P 16`, then a new v2/v3 signature). The manifest does not set `pageSizeCompat`.
- `ui/WorkspaceViewModel.kt` holds all state (`WorkspaceUiState`, one slice per project via `editProject`). Background threads post to Main before `editProject`.
- Tools implement `tools/Tool.kt`; registered in `buildAgentLoop` in the view model; grouped in `tools/ToolGroups.kt`; listed in `agent/Prompt.kt` and `tools/LoadToolsTool.kt`. A new tool touches all four plus `toolPhase` labels. `second_monitor` is in the remote group: it returns a host script for an extended display and opens that page in `MonitorActivity`. On Windows the page is `http://127.0.0.1:8791/` through adb reverse; `tools/adb-monitor.ps1` captures only the virtual display and maps touch onto it. The launcher forwards that loopback address into `MonitorActivity`. Linux adds a headless output only on Sway or Hyprland. `YouShouldKnow` reads the open chat locally and can show one note above the composer. It does not call a model and it does not change the Doctor score.
- `web_to_app` (device group) packs the `webviewshell` APK: it replaces the fixed-length package id and home-screen name, writes the page into assets, and signs with `apksig` and a key kept in the app's files. The agent then calls `install_apk`. The shell does not clone another app or change TLS.
- `agent/AgentLoop.kt`: failed-call dedup and read-only repeat skip (`READ_ONLY`).
- Skills: `agent/SkillLibrary.kt`, project scope `.ceditneuro/skills`, phone scope in app files. Built-ins in `agent/ResearchSkill.kt` (`ResearchSkill`, `StarterSkills` with a `.starter-written` marker so deleted starters stay deleted). `use_skill` with `on` false switches a skill off without deleting the file. `ru-translate` is the Russian translation procedure: original kept, Russian written beside it, levels P0–P6, cursor in `.ceditneuro/translate/state.md`. `net-map` draws `research/net-map.svg` from packet fields. `capture_dump` is a short VPN recording of this phone's public IPv4 into a pcap; the consent dialog is started for a result so it stays on screen. `read_dump` summarizes it without payloads. ICMP is recorded and not forwarded. The agent loop runs on `Dispatchers.Main.immediate`: a tool must suspend, not block, or switch to IO itself (`AgentLoop.OFF_MAIN` for file-only tools). A recorder TCP leg is a `SocketChannel` protected before connect and read and written through the channel, never its socket streams. `net_audit` stays on the phone's own private subnet and only connects. `debug_case` stores one failure investigation and will not record a cause, a fix, or a pass out of order. `ToolSession.present` is the set of built tools, so a group never offers a tool that is not registered. The active-skill cap is 12 000 characters, the same as the skill file cap, so a long procedure is not cut off.
- Health: skill `health`, tools `health_log`, `health_panel`, `health_trend`, and `health_index` in the `health` group. Rows live in `.ceditneuro/health/readings.tsv`, which space sync skips. A row is below or above only against the range saved with it. Trend math is min, max, mean, and last-versus-first. An existing `health.md` gains those steps; a deleted file stays deleted. The tools do not name a disease.
- Skills from the public directory: group `skills`, tools `find_skills` and `review_skill`. Search is `https://skills.sh/api/search`. The file is fetched only from `raw.githubusercontent.com` paths built from `owner/repo` and the skill id. `SkillAudit` blocks a dangerous prompt, a hidden command, malware, and a key before `save_skill` or `use_skill`. The adapted text is what may be saved. A deleted starter stays deleted.
- Design: skill `frontend-design`. `design_system` is in the `design` group and is not registered in the agent loop, so `load_tools` says that group has no tools and the agent reads the public page with `http_request`. The project's own design wins. Refero, awesome-design-md, component.gallery, and Kinetics are quoted from the page that was fetched. A bland draft picks one mood, two type faces, and drops empty chips. The Google design guide is read with `http_request`. Google AI Studio is not opened and an image generator is not called. A desktop window, an Android screen, and an iOS screen use the same skill. No MCP and no video renderer are installed. `DesignCatalog` holds public gallery names, vendors, card swatches, and page URLs. The agent writes one HTML file and quotes only printed colors. It does not copy a company product. `android-app`, `android-compose`, and `android-ui` are the phone procedures for an Android project's layers, Compose, and screen design. A build is done after BUILD SUCCESSFUL and install. `android-debug` checks that screen. A unit test is not the screen. A step from `github.com/android/skills` is followed only when that page printed it. `android-apk` reads an APK before it is trusted and does not copy its code.
- Reader place: `ReaderStore` on this phone (`reader-progress.json`), keyed by the canonical file path. `anchor` is the character offset. `ReaderPlace` maps that offset onto the pages that fit the current screen. Opening a book does not overwrite the saved place. The screen reports a new place only after it has laid the text out. A finger turn is handled on the reader itself: left third previous, right third next, center toggles the menu, a horizontal swipe turns the page. A Markdown link is colored text in the paragraph, wraps with the line, and takes the tap instead of turning the page. The vault index keeps up to 8000 notes. Back is a button under the page. A return and a heading jump use a character offset. Notes that link here are chips on the last page. `NoteVault` resolves `[[Note]]`, an alias, a heading, and `[words](note.md)` inside the project, and caches that lookup. The same folder wins. A fenced block and a web address stay text. Plain notes keep the same links. The menu is drawn after that gesture, so its buttons keep the tap. A full-page photo handles the same zones inside its pinch view. A scheme handles them in the WebView: one tap uses the zone, a second tap within 320 ms opens the scheme. Volume keys still turn pages. Limiting prompts are catalogued in `memory-bank/promptLimits.md`.
- Deep research: `research_run` stores one study in `research/run.md` and a source list in `research/sources.md`. A reprint does not count. A cite has to use the quote. The run says pass only after the tier's sources, critics, and supported cites. A later chat reads `action=status` and continues. It does not install another harness and does not run a dissertation-length study. A locator that was not printed by a tool is rejected once; the next guessed locator is the same failure.
- A failed `http_request` for a certificate or an HTTP 522 blocks that host. The shell does not run a heredoc, a `timeout` wrapper, or a pipe through `sed`. Two refusals of a call that already failed end the turn.
- Video notes: `video_brief` reads one public YouTube, RuTube, or Yandex page and returns title, author, description, and captions. action=search, action=channel, and action=playlist return YouTube titles only. action=batch reads up to 3 pages. It does not download the video and it does not sign up for a transcript service. A stream host is refused. No captions means the picture was not seen.
- `learn` (group `learn`) is the lesson tool, adapted from Concept Loom. `action=frame` hides the rationale. `action=assess` scores a choice and stores an open verdict. The notebook is `learn/notes.md`. The resume point is `.ceditneuro/learn/sessions`. The release APK file name is `CEditNeuro-<versionName>.apk`.
- `crew` (group `crew`, skill `crew`) is the shared queue for every phone on one link, adapted from DeLM. `BeaconClient.relay` sends `CREW` lines through the server so a third phone sees them. The board is `.ceditneuro/crew/board.txt`. A claim carries a stamp; the earlier stamp keeps the task. Notes are FACT, FAIL, and DONE, capped at 30. `HERE` replies with a snapshot that is merged, not replaced. A user prompt on a live link adds the goal and does not send TASK. A finished run marks this phone's claims done, or releases them and posts FAIL. An idle phone starts only when another phone adds a task or sends a snapshot that still has an open task. The folder push stays with the phone that created the code. The status line says Linked N.

- `tools/PageCheck.kt` (from agent-reach, MIT): `isChallenge` marks a Cloudflare or reader captcha page, `isPublic` allows only a public http(s) host with no login, and `readerRefusal` reads the reader's "Target URL returned error" line. `http_request` returns these as errors, so the failed-call rule stops a retry. `web_search` is in both the study and video groups.
- The composer hides Send only while Android reports no validated network. `linkDown` is a latch for a DNS failure on a network that stayed validated; it clears on the next validated reading, on resume, on Check again, or from a 4-second watch. A model stall (`ModelStall`) is a chat error, not that latch.
- Harness edits go through `harness_rrsi` (skill `rrsi`). The search follows the RRSI budget, floor, cost rule, stall, and prune. The Doctor score counts tool failures and the same problem coming back in the chats and texts, and the report keeps the kind, not the sentence. A draft that special-cases one task, one chat, one wording, or carries a key is not stored. The model weights are not updated.
- Models: every provider is OpenAI-compatible and goes through `DeepSeekBackend`. A read with no bytes for 90 seconds ends the turn. A web SSE error or status FAILED ends it immediately and is not retried when it is a stall. A provider is usable when `ready` (a key, or `keyless` for a local bridge). `ContextBudget.fit` fits each request into `maxContextTokens - maxOutputTokens`, so a small-context model such as the 64K DeepSeek web bridge keeps working on a long chat. Errors inside the SSE stream are thrown, not skipped. `deepseek-web-phone` is handed to `web/DeepSeekWebBackend` (chat.deepseek.com, PoW, fenced tool calls, session in `WebSessionStore`). `qwen-web-phone` is handed to `qwen/web/QwenWebBackend` (chat.qwen.ai, SPA body version 2.1, `<tool_call>` JSON, session in `QwenSessionStore`). Both parsers accept a fence and XML, so a tool call in either shape is executed.
- Audio for a composition: `SfxLibrary` (bundled samples), `MusicSynth` (procedural bed), `Speech` (TTS), mixed by `AudioMix` into the `Mp4Encoder` AAC track. Players live in `ui/editor/Players.kt`.
- Shell: `shell/DeviceShell.run(onProcess, onOutput)` gives live output and a process handle for Stop. `shizuku_exec` uses the Shizuku binder when that server is already running as uid 2000, otherwise su. A raw socket between the app and a shell process is blocked on this phone. The app does not grant itself uid 2000 and does not open the Shizuku app. `scripts/start-shell.ps1` starts the installed Shizuku server from the existing wireless adb link.
