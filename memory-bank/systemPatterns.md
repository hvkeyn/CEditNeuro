# System patterns

- `ui/WorkspaceViewModel.kt` holds all state (`WorkspaceUiState`, one slice per project via `editProject`). Background threads post to Main before `editProject`.
- Tools implement `tools/Tool.kt`; registered in `buildAgentLoop` in the view model; grouped in `tools/ToolGroups.kt`; listed in `agent/Prompt.kt` and `tools/LoadToolsTool.kt`. A new tool touches all four plus `toolPhase` labels.
- `web_to_app` (device group) packs the `webviewshell` APK: it replaces the fixed-length package id and home-screen name, writes the page into assets, and signs with `apksig` and a key kept in the app's files. The agent then calls `install_apk`. The shell does not clone another app or change TLS.
- `agent/AgentLoop.kt`: failed-call dedup and read-only repeat skip (`READ_ONLY`).
- Skills: `agent/SkillLibrary.kt`, project scope `.ceditneuro/skills`, phone scope in app files. Built-ins in `agent/ResearchSkill.kt` (`ResearchSkill`, `StarterSkills` with a `.starter-written` marker so deleted starters stay deleted). `use_skill` with `on` false switches a skill off without deleting the file. `ru-translate` is the Russian translation procedure: original kept, Russian written beside it, levels P0–P6, cursor in `.ceditneuro/translate/state.md`. `net-map` draws `research/net-map.svg` from packet fields. `capture_dump` is a short VPN recording of this phone's public IPv4 into a pcap; the consent dialog is started for a result so it stays on screen. `read_dump` summarizes it without payloads. ICMP is recorded and not forwarded. The agent loop runs on `Dispatchers.Main.immediate`: a tool must suspend, not block, or switch to IO itself (`AgentLoop.OFF_MAIN` for file-only tools). A recorder TCP leg is a `SocketChannel` protected before connect and read and written through the channel, never its socket streams. `net_audit` stays on the phone's own private subnet and only connects. `debug_case` stores one failure investigation and will not record a cause, a fix, or a pass out of order. `ToolSession.present` is the set of built tools, so a group never offers a tool that is not registered. The active-skill cap is 12 000 characters, the same as the skill file cap, so a long procedure is not cut off.
- Health: skill `health`, tools `health_log`, `health_panel`, `health_trend`, and `health_index` in the `health` group. Rows live in `.ceditneuro/health/readings.tsv`, which space sync skips. A row is below or above only against the range saved with it. Trend math is min, max, mean, and last-versus-first. An existing `health.md` gains those steps; a deleted file stays deleted. The tools do not name a disease.
- Skills from the public directory: group `skills`, tools `find_skills` and `review_skill`. Search is `https://skills.sh/api/search`. The file is fetched only from `raw.githubusercontent.com` paths built from `owner/repo` and the skill id. `SkillAudit` blocks a dangerous prompt, a hidden command, malware, and a key before `save_skill` or `use_skill`. The adapted text is what may be saved. A deleted starter stays deleted.
- Design: skill `frontend-design`, tool `design_system` in the `design` group. `DesignCatalog` holds public gallery names, vendors, card swatches, and page URLs. The agent writes one HTML file and quotes only printed colors. It does not copy a company product.
- Reader place: `ReaderStore` on this phone (`reader-progress.json`), keyed by the canonical file path. `anchor` is the character offset. `ReaderPlace` maps that offset onto the pages that fit the current screen. Opening a book does not overwrite the saved place. The screen reports a new place only after it has laid the text out. A finger turn is handled on the reader itself: left third previous, right third next, center toggles the menu, a horizontal swipe turns the page. The menu is drawn after that gesture, so its buttons keep the tap. A full-page photo handles the same zones inside its pinch view. A scheme handles them in the WebView: one tap uses the zone, a second tap within 320 ms opens the scheme. Volume keys still turn pages. Limiting prompts are catalogued in `memory-bank/promptLimits.md`.
- Deep research: `research_run` stores one study in `research/run.md` and a source list in `research/sources.md`. A reprint does not count. A cite has to use the quote. The run says pass only after the tier's sources, critics, and supported cites. A later chat reads `action=status` and continues. It does not install another harness and does not run a dissertation-length study.
- `SecretText` rejects keys in anything the agent writes.
- Shell: `shell/DeviceShell.run(onProcess, onOutput)` gives live output and a process handle for Stop.
