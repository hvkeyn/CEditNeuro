# Project brief

CEditNeuro is an open-source Android app (package `com.hvkeyn.ceditneuro`, installed id `com.hvkeyn.ceditneuro.debug`): a code editor, a book reader, a shell, and an agent harness over DeepSeek-style tool calling.

Goals:
- A pocket tool for research, debugging, rest, and reference on one phone, with or without root.
- The agent stays cheap: core tools always, other groups load through `load_tools` or the work focus.
- Nothing secret leaves the phone or enters the repository.
