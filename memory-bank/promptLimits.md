# Ограничивающие промпты

Каталог текстов, которые ограничивают агента. Это не список к удалению: строки остаются как написаны. Сюда входят системный промпт, текст встроенных скиллов и ответы инструментов, которые модель читает в следующем шаге. Комментарии в коде и исключения, которые пользователь не видит, сюда не входят.

Код, который отказывает сам, без текста для модели, стоит в конце отдельно.

Смягчено по просьбе пользователя: доступ к данным других приложений на телефоне больше не ограничивается, потому что запрет ломал функционал. Правила 15, 45, скилл `security`, `AgentDoctor`, `ShizukuExecTool` и `Workspace.resolve` приведены к этому, проверка `isReachable` из `Workspace` удалена. Второй телефон тоже отдаёт данные: правила 46 и 47 и `SpaceSyncTool` говорят, что напарник копирует запрошенный файл в общую папку.

## 3. Ответы, которые модель читает следующим шагом

Эти строки пишет код в результат инструмента или в следующее системное сообщение. Модель видит их и должна им следовать.

### Агент и оболочка

| Где | Функция | Ограничение |
| --- | --- | --- |
| `agent/AgentDoctor.kt` | отчёт и `advice` | Разрешения не выдумывать. Отказанный путь не повторять. Повторно не вызывать layout, Shizuku, тот же хост, тот же логин, `/proc/net`, screencap. Остановленный ход не начинать с нуля. |
| `agent/AgentLoop.kt` | продолжение обрезанного ответа | Не повторять законченные шаги. Упавший вызов не повторять: сменить путь, аргументы или инструмент. |
| `shell/ShellExit.kt` | примечание после команды | Пустой поиск не повторять. logcat не запускать. Сертификат и логин не повторять. Уже записанный файл не писать той же командой. Упавший прокси не вызывать. |

## 4. Где это пишется

Один и тот же запрет часто записан дважды: коротко в системном промпте и подробно в скилле или в ответе инструмента.

| Место | Когда попадает к модели |
| --- | --- |
| `Prompt.buildSystemPrompt` | Каждый ход, как постоянная инструкция. |
| `Prompt.buildSetupPrompt` | Каждый ход: путь, правила проекта, каталог скиллов, текст уже включённых скиллов (до 12 000 символов на скилл). |
| `ResearchSkill.StarterSkills` | Файл скилла на телефоне. В ход попадает после `use_skill`, через setup-промпт. |
| `SkillAudit` | Ответ `review_skill` и отказ `save_skill` / `use_skill`. |
| `SecretText` | Отказ, если агент пишет ключ в скилл или память. |
| `DebugCase.apply` | Ответ `debug_case`. |
| `AgentDoctor` | Отчёт, который пользователь может отправить обратно в чат. |
| `ShellExit`, `AgentNet` | Примечание в результате команды или HTTP. |
| Описания в `tools/*.kt` | Схема инструмента, когда группа загружена через `load_tools`. |
| `WorkspaceViewModel` | Строка в чат от лица приложения, следующий ход её видит. |
